# Project Brief

This repository is expected to become a local driving-school operating system.

Current direction:

- Product for one local driving-school company, not SaaS.
- Laravel + Orchid admin panel.
- Public website plus internal admin/back-office.
- Main modules planned: website, CRM leads, students, groups, schedule, instructors, vehicles, documents, payments, analytics.
- Superadmin is the highest local admin inside the driving school, not a platform/SaaS owner.
- The product should support multilingual UI and content management.
